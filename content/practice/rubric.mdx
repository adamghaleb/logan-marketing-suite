## How to use this

Run any finished page or section through this before showing it to anyone — Adam, the lead designer, the PM, the client. Five dimensions, scored 1–5 each. Total out of 25.

- **22–25**: ship clean. Hand off with confidence.
- **18–21**: ship with a note flagging the weakest dimension.
- **Below 18**: don't ship yet. Pick the lowest-scoring dimension, fix it, re-score.

You'll be too generous on yourself the first few times. That's fine. The point is to start noticing the same things twice.

---

## 1. Warmth (1–5)

Does this feel like a real place built by real people? Or does it feel like a template?

| Score | What it looks like                                                                                              |
| ----- | --------------------------------------------------------------------------------------------------------------- |
| 5     | A specific human shows up. The dog has a name. The breakfast has a day. The porch has been sat on.              |
| 4     | Specific in spirit but a few sentences could be tightened toward a real detail.                                 |
| 3     | Generally pleasant but reads more like "a B&B" than "this B&B."                                                 |
| 2     | Branded vagueness — "passion," "experience," "unforgettable." A clichés audit would flag at least three things. |
| 1     | Could be any inn anywhere. Swap the property name and nothing else changes.                                     |

The fix when warmth is low: ask the client for one concrete detail per section. The dog, the breakfast, the porch swing, the road they came up. Specifics carry warmth.

---

## 2. Clarity (1–5)

Is it instantly obvious what this page is for and what to do next?

| Score | What it looks like                                                                    |
| ----- | ------------------------------------------------------------------------------------- |
| 5     | A new visitor knows in 5 seconds what the page is about and what their next click is. |
| 4     | Mostly clear; the next-click is there but takes a moment to find.                     |
| 3     | The page is a bit cluttered or the CTA is buried.                                     |
| 2     | Two CTAs competing, or the page tries to do three things at once.                     |
| 1     | The visitor would have to read closely to understand what to do.                      |

The fix when clarity is low: cut something. Almost always. One CTA, one main message, one next step.

---

## 3. Image choice (1–5)

Are the photos doing the work they should be doing? Are they the right ones for this page?

| Score | What it looks like                                                                                                 |
| ----- | ------------------------------------------------------------------------------------------------------------------ |
| 5     | Photos feel like they came from the same shoot. Same light, same season, same hand. The hero photo earns its size. |
| 4     | Mostly cohesive, one photo is a slightly different shoot or season.                                                |
| 3     | Photos are fine but feel like a stock library — competent, not memorable.                                          |
| 2     | One or more photos are obvious stock. Or contrast on the hero is bad.                                              |
| 1     | Stock everything. Or photos that contradict each other (sun-drenched + cold-blue mixed in one grid).               |

The fix when image choice is low: ask the lead or photographer for the next-best images you haven't tried yet. Or change the layout to use fewer, better photos.

---

## 4. Type rhythm (1–5)

Does the page have a calm, readable cadence? Or does the type feel busy and uneven?

| Score | What it looks like                                                                         |
| ----- | ------------------------------------------------------------------------------------------ |
| 5     | Clear hierarchy, good line-height, generous space between sections. Eye knows where to go. |
| 4     | Mostly good; one heading is competing with another, or one paragraph is cramped.           |
| 3     | A bit busy. Multiple weights and sizes that don't quite earn their differences.            |
| 2     | Heading hierarchy is broken (H3 before H2, or two H1s on a page). Globals not used.        |
| 1     | Chaotic — random font sizes, local-overrides everywhere, no visible system.                |

The fix when type rhythm is low: reset everything to Globals first. Then check that headings go H1 → H2 → H3 in order. Then look at line-height and spacing.

---

## 5. Mobile feel (1–5)

What does this look like on a real phone, in a real hand, with a real thumb?

| Score | What it looks like                                                                                             |
| ----- | -------------------------------------------------------------------------------------------------------------- |
| 5     | Feels designed for the phone, not adapted to it. Tap targets comfortable. Photos crop right. Type is readable. |
| 4     | Mostly good; one tap target is small, or one image's focal point is slightly off.                              |
| 3     | Functional but flat. Looks like the desktop design squashed.                                                   |
| 2     | Visible problems — overlapping text, tiny tap targets, image clipping awkwardly.                               |
| 1     | The mobile view is broken in a way that would embarrass at handoff.                                            |

The fix when mobile feel is low: open it on an actual phone. The mobile editor view doesn't catch everything. Walk through the page with your thumb, not your trackpad.

---

## How to score honestly

- Don't average mentally. Score each one separately, write it down.
- Be harder on warmth than on type rhythm — type is recoverable later, warmth often isn't.
- If you're tempted to round up to "ship it," don't. The score is for you, not the PM.
- After three weeks of using this, your floor will rise. The early scores feel high; the later ones feel earned.

---

## When to skip the rubric

- Tiny one-off changes (a typo fix, an image swap on an existing approved page).
- Anything still in active build (the rubric is a finishing tool, not a building tool).
- When you're stuck on something specific — debug first, score after.
